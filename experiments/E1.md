This file explains the first experiment (Figure 2 of the authors) methodology. In a first time we re-use the exact same architecture and training process as the authors which means:

Dataset: MNIST, statically binarized --> torchvision.datasets.MNIST(download=True). Instead of working with the usual grey's level, every pixel is maped into a black or white one with probability corresponding to its grey value, where the probability eis given by $p = P(X = 1) = value/255$ 

Why binarize MNIST ? It enables the computation of log p(x)

Encoder q(z|x): 784 - 100 - 4 (size of the fully connected networks)

input: $x \in \{0,1\}^{784}~~  (784 = 28*28)$. The image is flatten and each pixel of the total is either white (value = 0) or black (value = 1). The hidden layer has size 100 and the encoder produces a vector of size $2d$ where $d$ is the size of the latent vectors. Why $2d$ because the encoder does not produce a vector $z$ directly but produces $\mu \in \mathbb{R}^d$ and $\sigma \in \mathbb{R}^d$ Then the vector is given by z ~ q(z|x) = $\mathcal{N}(\mu, diag(\sigma^2))$. In the case of $d = 2$ for the Figure 2, the encoder thus produces a vector of size 4.


Decoder $p(x|z)$: 2 - 100 - 784 

input: a vector of size 2 given by $z ~ q(z|x)$. The hidden layer has size 100 and it maps back to $x \in \{0,1\}^{784}$ which is the original image size.

activation function: tanh
optimizer: Adam
lr = 1e-4
batch size $B = 50$

How to compute $\log p(x|z) +\log p(z)$ on a grid ?

we want the true posterior $p(z|x) = \frac{p(x|z)p(z)}{p(x)}$ from Bayes. 
$p(x) = \int p(x|z)p(z)dz$

$\log p(z) = -\frac{1}{2}\log(2 \pi) - \frac{1}{2}||z||^2$
We can then pass z through the decoder to get $\pi(z) \in (0,1)^{784}$. Finally, $\log p(x|z) = \sum_{i=1}^{784} x_i \log \pi_i(z) + (1 - x_i)\log (1 - \pi_i(z))$
